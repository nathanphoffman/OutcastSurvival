# Outcast Survival

A wave-survival map for Jedi Outcast (single player). Two maps:
- `survival_chasm` (default): a Cloud City style chasm with a glowing reactor core through the middle, a hub deck,
  spokes out to four platforms, four raised platforms reached by ramps, and a big flat outer rim. Generated by `mapgen.py`.
- `survival_pit`: the original arena (the game's `pit` map with new entities). Build/run it with `SURV_MAP=survival_pit`.

## Setup (once)
Link the mod folder into the game so it loads as its own game dir (`base` is untouched):

    cd "$HOME/.steam/steam/steamapps/common/Jedi Outcast/GameData"
    ln -s /home/nate/Code/OutcastSurvival/survival survival

## Build
    python3 build.py

Reads `pit.bsp` from the game's `assets0.pk3` and writes `survival/zz_survival.pk3`.

## Run
    ./run.sh

Rebuilds the map with a new random seed, then launches the game once with `+set fs_game survival +devmap survival_pit` (cheats on). Normal
launches from Steam are unaffected.

## How waves work
- Wave 1 (stormtroopers plus one BattleDroid) spawns on map load; the first one starts the wave clock.
- Each later wave starts on a timer ((30 + 4n)/3 seconds after the previous wave started), whether or
  not you cleared the last one. Enemies spawn ~0.6s apart on a ring around the arena.
- 20 waves, 160 enemies total (3 + n/2 per wave). Enemy types per wave and timings are at the top of `build.py`.

## Drops and upgrades
- Every wave, one hidden health/shield pickup (small shield, medpak or large shield, weighted toward
  the small ones) appears at a random spot. Picked by the game's `target_random`, so it varies per run.
- Every 2nd wave a battery-looking pickup appears; grabbing it raises one force power one level
  (8 force powers + saber throw/defense/offense, levels 1-3). The sequence is chosen at build time
  (`./run.sh` rebuilds each launch; `python3 build.py <seed>` repeats one). Rules: a power must be at
  level L-1 before L, and at least half the powers (6 of 11) must be at level >= L-1 before any power can
  reach level L (L>=2).
- Upgrades are compiled ICARUS scripts (`scripts/zzsurv/*.ibi`) written by `build.py`; the format
  matches the game's own scripts byte for byte.
- At start all powers reset to 0 (saber offense/defense 1).

## Score
Every enemy has a `deathscript` that pokes a chain of `target_counter`s; the k-th death fires a
`target_print` showing "Kills: k   Score: k*100" (center of screen - the game has no way to draw a HUD
element from map entities). Costs ~2 entities per kill, so keep an eye on the entity count `build.py` prints.

## Notes
- Entity classnames are case-sensitive (`NPC_Stormtrooper`, not `NPC_StormTrooper`).
- Trigger names are prefixed `surv` because the map's waypoints already use `w1`..`w13`.
- NPC `target` fires on spawn, not death, so waves are timer-based.

## Self-built engine (OpenJO) - separate from Steam and other projects
- Source: `openjk/` (shallow clone of github.com/JACoders/OpenJK, GPLv2). Build output: `dist/`.
- Build: `cd openjk/build && ninja && ninja install` (configured for JK2 single player only;
  cmake flags in this repo's history: `-G Ninja -DCMAKE_INSTALL_PREFIX=../../dist` + `BuildJK2SP*=ON`, others OFF).
- Run: `./run_open.sh` (rebuilds the map, then starts the engine on `survival_pit`).
- `game/base` = symlinks to the Steam assets (read-only use) + our pk3; `game/OpenJK` -> `dist/JediOutcast/OpenJK`.
  Configs/saves go to `home/`, so nothing touches the Steam install or other mods.
- `openjk/`, `dist/`, `game/`, `home/` are git-ignored.

## Chasm map (mapgen.py)
- `mapgen.py` writes brushes/lights/waypoints as a .map; `build.py` adds the wave entities, then runs `q3map2`
  (meta, vis, light) and packs the .bsp into the pk3. Edit the numbers/lists in `mapgen.py` to reshape the map.
- Compiler: `tools/netradiant/` (shallow clone of netradiant-custom, only `q3map2` built; one line patched in
  `q3map2.h` for g++ 13). Helper libs in `tools/libs/`. Build: `cd tools/netradiant && DEPENDENCIES_CHECK=off make binaries-q3map2`
  (needs libxml2-dev and libassimp-dev headers; we unpacked the .debs locally since there is no sudo).
- AI navigation (.nav) is recalculated by the game on the first load after each rebuild (a few seconds).
- Falling below the platforms hits a `trigger_hurt` and kills instantly.

## Enemy personalities
Enemies are tagged in `build.py` (`PERSONALITIES`, via the NPC_targetname key) and handled by a patch to the trooper AI in
`openjk/codeJK2/game/AI_Stormtrooper.cpp` (search `ST_PERS_`), so they only apply with the self-built engine (`./play_open.sh`);
under Steam (`run.sh`) the tags are ignored and enemies use the stock AI. Tagged troopers always know where you are.
- `p_rusher`: charges you along the waypoint paths and stops when on top of you.
- `p_sniper`: holds 650-1300 units away with a line of sight; backs off if you close in; moves again when you leave its view.
- `p_coward`: skirmishes at 450-900; bolts away for a few seconds when you get within 450, then returns.
- Only trooper-type NPCs (stormtrooper, swamptrooper, officer...) use these; Reborn/Jedi types have their own AI.
- To tune: change the numbers in `ST_PersonalityMove`, then `cd openjk/build && ninja install`.
- Navigation: JK2 only paths along waypoints that are explicitly linked (target keys), so `mapgen.py` links its waypoints itself
  (`link`/`chain`). The AI's straight-line shortcut ignores floors, so enemies would cut corners off the edges; `mapgen.py` adds
  invisible NPC-only fences (`fence`, texture `blocknpc`) along every edge. Add both when you add walkable areas.

## BattleDroid (wave 1 robot)
A heavy robot with its own model, built by `droidgen.py` (called from `build.py`; output cached in `tools/build/droid/`).
- Model: boxes/cylinders/spheres skinned onto the game's humanoid skeleton by copying bone weights from the stormtrooper
  model, plus a generated texture, glow map, shader, skin and `ext_data/battledroid.npc`. Edit `build_parts()` to reshape it.
- AI: `openjk/codeJK2/game/AI_BattleDroid.cpp` (new class `CLASS_BATTLEDROID`, entity `NPC_BattleDroid`), engine build only.
  - Twin arm cannons fire bursts (left rapid bolts, right heavy plasma) while it stands still.
  - Shoulder pods fire a salvo of homing rockets at long range.
  - Close range: ground slam that damages and knocks you down.
  - Armor plating, never knocked back; below 40% health it goes into overdrive (faster, sparking).
  - On death the reactor overloads for ~2 seconds, then explodes and hurts anything nearby.
- Tuning numbers (health in `droidgen.py` NPC_TXT; everything else at the top of `AI_BattleDroid.cpp`), then `cd openjk/build && ninja install`.
